How PassRadar works

  1. Hash locally. Your password is turned into a SHA-1 hash inside your browser using the Web Crypto API — it never leaves your device.
  2. Send a fragment. Only the first 5 characters of that hash go to the Have I Been Pwned API. This is called k-anonymity: the API can't tell which password you're checking.
  3. Match locally. The API returns every hash sharing that fragment, and PassRadar checks for your exact match right here in the browser.

Built by Fatima Ali as a hands-on look at breach-data APIs and client-side cryptography. Not a substitute for a password manager.
